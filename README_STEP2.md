# Step 2 — Property Registration Foundation

This is an overlay package for the existing Step 1 Laravel + Vue project. It follows the established architecture:

Controller → Service Interface → Service → Repository Interface → Repository → Eloquent Model

Frontend structure remains pages → Pinia stores → API module → shared Axios client. The package adds a property registration API, list/create screens, and a Pinia store. It does not replace the existing dashboard, authentication, HTTP client, or layout.

## Scope based on the supplied PIMS specification

Implements the property fields described in the specification's pages 4–5: basic information, physical specifications, availability/legal status, and asking-price information. The specification treats owner contact details and final negotiated price as restricted information. Those fields are intentionally excluded from this general inventory API and must be implemented separately with explicit authorization.

## Install

1. Extract this ZIP into the existing Laravel project root and merge folders. Do not replace the whole project.
2. In `app/Providers/RepositoryServiceProvider.php`, add the imports and bindings shown in `app/Providers/RepositoryServiceProvider.php.append.txt`.
3. In `routes/api.php`, add the controller import and API resource routes shown in `routes/api.php.append.txt` inside the existing `Route::prefix('v1')->group(...)`. Keep the existing auth routes.
4. In `resources/js/router/index.js`, add the two route objects from `resources/js/router/index.js.append.txt` to the existing `routes` array.
5. In `resources/js/config/modules.js`, change the `inventory` module's `route` from `null` to `'properties.index'`.
6. Run:
   ```bash
   php artisan optimize:clear
   php artisan migrate
   ```
7. Run the existing Laravel and Vite servers.

## API

All routes require the existing Sanctum session:

- `GET /api/v1/properties`
- `POST /api/v1/properties`
- `GET /api/v1/properties/{property}`
- `PUT/PATCH /api/v1/properties/{property}`

The property code is generated by the service and cannot be supplied by the client.

## Important current blocker
